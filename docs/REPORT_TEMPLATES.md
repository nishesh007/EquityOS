# Report Templates

Sprint 11B.4

Reusable templates in `REPORT_TEMPLATES`:

| ID | Label | Focus |
|---|---|---|
| `executive` | Executive Report | Summary, strategy, benchmark, risk, insights |
| `strategy` | Strategy Report | Strategy + benchmark + trade log |
| `recommendation_validation` | Recommendation Validation Report | Quality + calibration |
| `benchmark` | Benchmark Report | Excess vs Nifty indices |
| `risk` | Risk Report | Failure attribution + risk narrative |
| `backtest_session` | Backtest Session Report | Full appendix |

Templates only select sections — they do not recompute validation metrics.
