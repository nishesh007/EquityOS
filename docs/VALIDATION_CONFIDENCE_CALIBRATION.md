# Confidence Calibration

Sprint 11B.3

Conviction buckets:

| Bucket | Range |
|---|---|
| Low | &lt; 55 |
| Medium | 55–70 |
| High | 70–85 |
| Elite | ≥ 85 |

Per bucket: trade count, win rate, average return, profit factor.

**Calibration gap** = expected win rate for bucket − realized win rate.  
Gaps with \|Δ\| ≥ 12 points are highlighted as miscalibration.
